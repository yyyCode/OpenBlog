# 首页改版：两屏全屏滚动（口号区 + 文章区）

日期：2026-08-28
状态：✅ 已实现（2026-08-28）。已确认（用户拍板：口号「热爱技术 持续生长」宋体衬线大字、「热爱」「生长」蓝色渲染、纯白背景、预留图片/视频背景配置；第二屏放精选大卡片 + 最新文章，保留现有样式；滚动吸附、屏与屏不越界）

## 背景与目标

当前首页是普通单页：顶部 hero（标题+副标题+图）+ 精选文章大卡片 + 最新文章 3 卡，整个页面随浏览器正常滚动。

目标：仿字节官网的**整屏区块滚动**效果——首页拆成 **2 个全屏区块**，每个区块内容刚好占满一个可见视口，滚动吸附，**口号整屏显示时绝不露出下方文章区**。

**范围：纯前端。** 后端零改动；口号/副标题/背景图全部复用现有 siteConfig 字段，管理员可在控制台直接修改。

## 设计

### 页面结构（HomeView.vue 重写）

```
┌─────────────────────────────┐
│ 第 1 屏 · 口号区（全屏）       │
│   热爱技术 持续生长（宋体大字）  │
│   热爱/生长 = 蓝色 #3370ff     │
│   副标题（小字，可选）          │
│   底部「▼ 下滑」提示            │
├─────────────────────────────┤
│ 第 2 屏 · 文章区（全屏）       │
│   精选文章大卡片（现有样式）     │
│   最新文章 3 张小卡片（现有样式） │
└─────────────────────────────┘
```

### 第 1 屏 · 口号区

- **口号**：一行大字「热爱技术 持续生长」，宋体衬线（`font-family: 'Songti SC','SimSun','Noto Serif SC',serif`）、粗体、字距拉开、居中。
- **蓝色高亮**：「热爱」「生长」渲染为蓝色 `#3370ff`（亮色主题强调色）。
- **背景**：默认**纯白**。若 siteConfig `hero_image_url` 非空，则整屏改为该图片背景（cover 铺满）。视频背景（`hero_video_url`）**预留扩展位，本期不实现**。
- **副标题**：`hero_subtitle`，口号下方一行小字（换行用 `<br>`）。
- **底部**：「▼ 下滑」滚动提示（居中、弱化色）。
- 内容整体垂直水平居中。

**口号文案来源**：读 siteConfig `hero_title`（回退「热爱技术 持续生长」），并用字符串替换把「热爱」「生长」包上蓝色 `<span class="hl">`（见下）。这样管理员在控制台改了口号文案也能正常显示，只是不再命中高亮词（可接受）。

### 第 2 屏 · 文章区

- **精选文章大卡片**：沿用现有首页 `.home-featured` 结构（精选徽标 / 封面 / 标题 / 摘要 / 日期·作者 / 「阅读更多 →」），点击进详情。
- **最新文章**：沿用现有 `.home-latest-grid` 的 `.home-post-card` 小卡片，取 3 篇。
- 整屏纵向排布、居中、限制最大宽度（复用 `.blog-container`）；尺寸收紧保证**一屏放得下**；极端矮屏（手机横屏/小窗）下区块自动变高、不裁剪内容（用 `min-height`，配合 proximity 吸附不影响）。

### 滚动行为

- 导航栏是 `position: sticky`、实底、占顶部约 60px（`min-height:52px` + 上下 padding，含安全区）。首页必须用吸顶导航「下方」的可见区域来算一屏，否则屏与屏会互相越界、或被导航遮住。
- 做法（三件套，缺一不可）：
  1. 每屏高度 = `calc(100dvh - var(--header-h))`，用 **dvh** 适配移动端地址栏收放。
  2. 滚动容器加 `scroll-padding-top: var(--header-h)`：吸附目标从导航底部开始算，第二屏被吸附时顶部正好在导航下方、不被遮挡。
  3. `--header-h` 在 HomeView `onMounted` 时用 JS 实测 `.site-top-bar` 的 `offsetHeight` 写入根元素 CSS 变量（含安全区加成），**兜底 60px**；不硬编码，导航改高也不影响。
- **只在首页路由开启滚动吸附**：HomeView `onMounted` 给 `document.documentElement` 加类 `homepage-scroll-snap`，`onUnmounted` 移除。
- CSS（全局）：`html.homepage-scroll-snap { scroll-snap-type: y proximity; scroll-padding-top: var(--header-h); }`；两个区块 `scroll-snap-align: start;`。
- 用 `proximity` 而非 `mandatory`：兼容内容略超一屏的矮屏，避免浏览器跳过/抖动。

### 数据源（全部复用 siteConfig，后端零改动）

| siteConfig 字段 | 用途 | 现 DB 值 | 改后 |
|---|---|---|---|
| `hero_title` | 口号文案 | `设计，创造，思考未来` | `热爱技术 持续生长`（更新 site-config.sql + 线上库） |
| `hero_subtitle` | 口号下副标题 | `探索 AI、设计与技术的交集\n分享…` | 不变 |
| `hero_image_url` | 口号区图片背景（非空则用） | `''`（空→纯白） | 不变 |
| `hero_video_url` | 视频背景（预留，未实现） | 无此字段 | 只在 spec 记录，不加字段 |

## 改动清单

| 文件 | 操作 |
|---|---|
| `vue/src/views/HomeView.vue` | **重写**：两屏结构（口号区 + 文章区），数据加载逻辑保留（featured/latest 拉取、loading、点击进详情） |
| `vue/src/assets/blog.css` | 新增全屏区块 / 吸附 / 口号字体 / 蓝色高亮 `.hl` 的全局样式；定义 `--header-h` |
| `sql/site-config.sql` | `hero_title` 默认值改为「热爱技术 持续生长」 |

**不动**：BlogHeader / App.vue / 路由 / 其它页面 / 后端。首页其它区块（项目推荐、关于我）不加入。

## 错误处理

| 场景 | 表现 |
|---|---|
| 文章接口失败 / 无文章 | 第二屏显示现有「暂无文章」占位文案，不报错不跳转 |
| `hero_image_url` 为空 | 口号区纯白背景 |
| 图片背景加载失败 | 纯白背景兜底（背景色垫底） |
| 极矮视口 | 区块自动增高（min-height），内容不裁剪；吸附 proximity 不锁死 |
| 口号文案不含「热爱/生长」 | 蓝色高亮不命中，整行普通颜色显示（不报错） |

## 验证

1. `cd vue && npm run build` 通过。
2. 手动回归（本地 `npm run dev`）：
   - 首页第 1 屏：纯白底、宋体大字「热爱技术 持续生长」、「热爱/生长」蓝色、副标题、底部下滑提示。
   - 下滑恰好落在第 2 屏：精选大卡片 + 最新文章 3 卡，一屏放下；**口号整屏时看不到文章区任何内容**。
   - 继续下滑不越界、无半屏卡顿；回到顶部再滑仍吸附。
   - 控制台把 `hero_title` 改成别的话 → 首页口号随之变化；`hero_image_url` 填图 → 口号区变图片背景。
   - 切到 `/all`、`/article/:id` 等其它页面 → 滚动恢复正常，无吸附。
   - 手机视口：口号区用 100dvh 正确占屏；文章区可自适应增高。

## 不做（YAGNI）

- 视频背景：本期只预留扩展位，不新增 `hero_video_url` 字段、不改控制台。
- 首页不加项目推荐 / 关于我 / 其它区块。
- 不改后端、不加接口、不加表。
- 不改吸顶导航样式（每屏高度用 `calc(100dvh - --header-h)` 适配，而非让导航透明悬浮）。
